# PLAN.md — reSpeaker XVF3800 마이크·스피커 교체 (ui-dev)

> 기존 저가 USB 마이크·스피커를 reSpeaker Flex XVF3800 (4-mic + 스피커)로 교체한다.
> 로봇 주행 없이 되는 작업. main·start_all은 건드리지 않는다.

## 배경 / 현재 상태 (2026-10-14)

- 기존: 스피커 UACDemoV1.0(카드0), 마이크 Usb Audio Device(카드1) — USB 1.1 저가형, 인식률 한계.
- 새 장치: **reSpeaker Flex XVF3800 Circular-4** (XMOS, 4-mic 어레이 + 10W 4Ω 스피커).
  - 온보드 DSP: AEC(에코 제거), 빔포밍, DNN 노이즈 억제, AGC, VAD, 360도 5m 집음.
  - USB-C로 UAC 2.0 연결. 16kHz 출력.
- **하드웨어 조립 완료**: 마이크 링 ↔ 메인보드(FPC), 스피커 ↔ SPEAKER 단자, USB-C ↔ Jetson 빈 USB 포트. **방금 꽂음.**
- 아직 전원은 USB 5V만. (스피커 음량 부족 시 PWR 12V 1.5A 추가 예정)
- 기존 마이크·스피커는 아직 안 뺌(비교/폴백용).

## 작업 체크리스트

### A. 인식 확인 (먼저, 설정 변경 전)
- [x] 1. `lsusb`, `aplay -l`, `arecord -l`, `cat /proc/asound/cards` 실행해서
      새 장치(XMOS/XVF3800)가 뜨는지, 입력·출력 둘 다 잡히는지, **카드 이름·번호** 확인·보고.
- [ ] 2. 안 뜨면 원인 점검: USB 케이블이 데이터용인지, USB 5V 전원 부족인지(→ 12V 단자).
      이 경우 바로 고치지 말고 보고.

### B. 간단 동작 테스트 (설정 변경 전, 임시)
- [ ] 3. 새 장치 카드 번호로 녹음·재생 임시 테스트:
      `arecord -D plughw:CARD=<새카드>,DEV=0 -f S16_LE -r 16000 -c 1 -d 3 /tmp/t.wav`
      `aplay -D plughw:CARD=<새카드>,DEV=0 /tmp/t.wav`
      마이크로 녹음되고 스피커로 재생되는지 확인.

### C. 앱 설정 변경 (A·B 성공 후)
- [x] 4. 앱이 마이크 입력을 새 장치로 쓰게 변경 (STT_AUDIO_DEVICE 등).
      현재 자동 감지 로직이 "Usb Audio Device"를 찾는데, 새 장치 이름에 맞게 수정.
      **카드 번호가 아니라 카드 이름 기준**으로 지정(재부팅 안전).
- [x] 5. 앱이 TTS 출력을 새 장치로 쓰게 변경 (TTS_SPEAKER_DEVICE).
      → AEC가 작동하려면 TTS 음성이 반드시 이 모듈을 거쳐 나가야 함.
- [x] 6. Whisper 입력 포맷(16kHz 모노)이 새 장치와 맞는지 확인. 채널 수(2ch/6ch) 처리 확인.

### D. 검증
- [ ] 7. 음성 문진 전 흐름 테스트: 말하기 → 인식 → 응답 음성.
      소음 환경에서 기존 대비 인식률이 나아지는지 체감 확인.
- [ ] 8. **AEC 확인**: 로봇이 안내 음성을 말하는 중에 사람이 말해도 인식되는지.
- [ ] 9. 결과를 문서(오디오 장치 정보)에 반영. 기존 마이크·스피커 제거.

## 주의사항
- main·start_all·로봇 주행은 건드리지 않는다. ui-dev / start_voice_ui 범위.
- A(인식)와 B(동작)가 성공하기 전에 앱 설정(C)을 바꾸지 않는다.
- 장치 지정은 카드 번호가 아니라 **카드 이름** 기준(USB 순서 바뀜 대비).
- 기존 오디오 장치 정보 문서(2.3절)를 최종적으로 새 장치 기준으로 갱신.
